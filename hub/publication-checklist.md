# Publication checklist

- [x] Dataset license declared as CC BY 4.0 (`cc-by-4.0`).
- [x] Model artifact license declared as Apache 2.0 (`apache-2.0`).
- [x] Source-code license declared as MIT with a root `LICENSE` file.
- [ ] Regenerate packages from a clean reviewed commit.
- [ ] Run all tests and `--validate-only` offline.
- [ ] Review every exported JSONL record.
- [ ] Verify SHA-256 hashes and `model.skops` trusted types.
- [ ] Confirm the challenge and its IDs are absent.
- [ ] Confirm there are no credentials, personal data, caches, or Transformer weights.
- [ ] Create separate Dataset and Model repositories manually.
- [ ] Keep repositories private during review if desired.
- [ ] Upload only the files listed in each package manifest.
- [ ] Cross-link dataset, model, and GitHub only after real URLs exist.
- [ ] Perform a final privacy, safety, and accuracy review before public visibility.
